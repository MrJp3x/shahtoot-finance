# حسابداری شاهتوت

برنامهٔ دسکتاپ فارسی برای پیگیری اقساط وام و چک‌های شیرینی‌فروشی شاهتوت. رابط با PySide6 ساخته شده و داده‌ها با SQLAlchemy در SQLite همین دستگاه ذخیره می‌شوند. اجرای برنامه به اینترنت یا حساب کاربری آنلاین نیاز ندارد.

## شروع کار در ویندوز ۱۱

۱. فایل `ShahtootFinance.exe` را در مسیر ثابتی روی ویندوز نگه دارید و برای اجرا روی آن دوبار کلیک کنید. فایل اجرایی شامل Python و وابستگی‌هاست.

۲. از «ثبت وام»، بانک، عنوان، اصل وام به تومان، تاریخ دریافت، سررسید نخستین قسط، تعداد و مبلغ اقساط را وارد کنید. برای وام، شمارهٔ قرارداد، یادداشت و زمان شروع یادآوری هم قابل ثبت‌اند. برنامه اقساط ماهانهٔ شمسی را تولید می‌کند. اگر یک ماه روز انتخابی را نداشته باشد، آخرین روز همان ماه استفاده می‌شود.

۳. روی کارت وام کلیک کنید تا برنامهٔ پرداخت باز شود. هر ردیف قسط با دوبار کلیک یا دکمهٔ «باز کردن قسط انتخاب‌شده» باز می‌شود. تاریخ سررسید، مبلغ، یادداشت و یادآوری هر قسط را می‌توانید جداگانه ویرایش کنید. پس از پرداخت، تاریخ واقعی تسویه را ثبت کنید. برای حذف وام، روی کارت آن راست‌کلیک کنید و «حذف وام» را بزنید. با تأیید، اقساط و سوابق پرداخت آن وام هم حذف می‌شوند.

۴. برای سررسید مستقل از «ثبت چک» استفاده کنید. چک دریافتی و پرداختی، شمارهٔ چک، بانک، طرف حساب، مبلغ و یادداشت قابل ثبت‌اند.

### یادآوری و اجرای پس‌زمینه

- زمان یادآوری را از «روز سررسید»، ۱، ۲، ۳ روز قبل یا عدد دلخواه انتخاب کنید. پیش‌فرض اولیه ۷ روز است و از تنظیمات قابل تغییر است.
- پس از ورود به ویندوز و آماده‌شدن ناحیهٔ اعلان، برنامه سررسیدهای باز در بازهٔ یادآوری را اعلام می‌کند. در زمان اجرا، اعلان هر ۳ ساعت تا زمان ثبت تسویه تکرار می‌شود. برنامه تاریخ محلی سیستم را می‌خواند و حدود هر دقیقه سررسیدها را بررسی می‌کند.
- اجرای خودکار در نخستین اجرای معمول برنامه روی ویندوز برای حساب کاربری همان فرد فعال می‌شود. پس از ورود به ویندوز، برنامه کنار ساعت در پس‌زمینه شروع می‌شود. بستن پنجره یادآوری را متوقف نمی‌کند. برای بستن فرایند، از منوی آیکون کنار ساعت «خروج کامل» را بزنید.
- برای بررسی روی رایانهٔ مقصد، از «تنظیمات ← آزمایش اعلان سیستم» استفاده کنید. نمایش اعلان تابع تنظیمات اعلان ویندوز است. موارد بازِ مشمول یادآوری در صفحهٔ «سررسیدها» و با نشان روی آیکون کنار ساعت هم دیده می‌شوند.
- اگر پوشهٔ برنامه را جابه‌جا کردید، برنامه را از مسیر جدید باز کنید و در تنظیمات دوباره اجرای پس‌زمینه را فعال کنید.

### داده‌ها و پشتیبان

- مسیر دقیق فایل `finance.sqlite3` در «تنظیمات» مشخص است. داده‌ها برای حساب کاربری همان رایانه ذخیره می‌شوند.
- «ذخیرهٔ نسخهٔ پشتیبان» یک کپی SQLite از تمام داده‌ها و سوابق تهیه می‌کند. برای بازیابی، ابتدا «خروج کامل» را بزنید و از فایل فعلی یک کپی بگیرید. سپس فایل پشتیبان را با نام `finance.sqlite3` در مسیر داده جایگزین کنید و برنامه را باز کنید.
- خروجی CSV اقساط و چک‌ها با سربرگ فارسی و مبلغ تومانی برای بررسی در نرم‌افزارهای صفحه‌گسترده آماده است.

## اجرای پروژه روی مک

در ترمینال، از داخل همین پوشه و با Python 3.11 اجرا کنید.

```sh
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

برای بررسی برنامه با داده‌های آزمایشی جدا از پایگاه اصلی می‌توان از `python main.py --data-dir ./test-data` استفاده کرد. ثبت اجرای خودکار برای مسیر آزمایشی انجام نمی‌شود.

## ساخت بستهٔ ویندوز

در PowerShell ویندوز ۱۱ و از داخل پوشهٔ پروژه، با Python 3.11 نسخهٔ x64 اجرا کنید.

```powershell
py -3.11 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
powershell -ExecutionPolicy Bypass -File .\packaging\build-windows.ps1 -Python .\.venv\Scripts\python.exe
```

فایل `dist/ShahtootFinance.exe` ساخته می‌شود. اسکریپت اجرای اولیهٔ فایل را هم آزمایش می‌کند.

اگر فقط به مک دسترسی دارید، این مخزن را به یک مخزن خصوصی در GitHub بفرستید. ساخت روی شاخهٔ `main` به‌صورت خودکار شروع می‌شود. می‌توانید از بخش **Actions** هم گردش‌کار **Windows x64 build** را دستی اجرا کنید. بعد از موفقیت، در بخش **Artifacts** همان اجرا، `ShahtootFinance-Windows-x64` را دانلود و فایل `ShahtootFinance.exe` را از آن استخراج کنید. ساخت روی محیط ویندوز GitHub انجام می‌شود. [مستندات PyInstaller](https://pyinstaller.org/en/stable/) · [دانلود خروجی GitHub Actions](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts)

برای تحویل به حسابداری، روی ویندوز ۱۱ یک چک آزمایشی با تاریخ امروز ثبت کنید، بستن پنجره و باز کردن مجدد از کنار ساعت را بررسی کنید و پس از ورود مجدد به ویندوز، اجرای خودکار و اعلان را تأیید کنید.
